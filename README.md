# 模式语言实验室 · Pattern Language Lab

依据 Christopher Alexander 与合作者的《A Pattern Language》，浏览全部 **253 项原书概括、出处、独立图解与三维概念场景**，在十个尺度中组合探索。所有尺度支持第一人称、自由相机和太阳控制；原有25项参数化经典住宅也继续保留。

[公开工作台](https://playwithexperiences.github.io/PWE-Visualize-The-Pattern-Language/) · [住宅三维漫游](https://playwithexperiences.github.io/PWE-Visualize-The-Pattern-Language/home.html)

## 完整图解与三维工作台

- 区域、城市、邻里、居住与机构、建筑场地、建筑平面、建筑边缘、房间、构造、生活细节，共253项。
- 每项有问题、原书原则的独立中文概括、PDF页序、候选印刷页范围和单项图形／三维操作。全局搜索名称、编号与内容。
- 在相同场景组合空间、路径、活动与构造；切换单项和未应用对照，查看作用与规则覆盖。75–78属于替代的居住方案。
- 跨尺度选择保留在同一方案。仅显式实现的跨尺度约束传播，例如21限制96的楼层、127改变私人床区位置、190影响构造场景的局部顶面、250改变房间暖色表面；并非所有原书关系都是自动依赖。
- 本机保存、并排比较、分享恢复、SVG导出和手机布局。
- 1,771条原书有向提及，按英文标题与括号编号同时匹配，不能视为完整网络或强制组合关系。

三维规则直接生成米制实体、门窗洞口、三角面屋顶、楼梯、家具、植被与灯光，不从SVG简单加厚。区域／城市共用聚落、建筑存量和交通骨架；住区与机构的公共设施分布于稳定站点，相关规则修改共享住宅、绿地与工作组。

支持1.65米眼高、真实门洞与台阶、上层地面、模式附近定位、1/3/10/20倍移动速度、顶盖剖开、三维并排比较、昼夜／手动太阳及局部点光。分享保存当前模式、相机类型和光照，时间播放在打开链接时暂停。

模型与图解表达项目的一种解释。多个选项可能争用位置或覆盖彼此；工具会标注无额外图形变化，但不自动解决所有冲突。这不是把253项同时生成成一栋完整建筑的工程系统，253项均有空间三维实现，但区域中的背景建筑有些仅为体量，不表示每栋都有可进入的内部细节，也不是写实建造模型。

## 经典住宅三维场景

`home.html` 保留25项参数化模型、轴测／平面／剖开外墙、人高1.65米行走、墙体和家具碰撞、自由飞行与升降、太阳时刻／流速／方位／高度。旧首页 `#v1=` 链接自动转入该场景，旧本机保存格式保留。

昼夜采用06:00日出、18:00日落的示意周期，不对应真实地理位置与季节；夜间不模拟室内灯。模型未进行结构、声学、日照、交通、无障碍或规范验算。

厨房139已放回共享侧；原有直角深窗框223和较粗窗格239仍是三维简化，完整图解分别展示向内展开的洞口与较细分格。

## 开发和验证

需要 Node.js 与 Python 3，无需安装依赖，无运行时第三方库或在线模型调用。

```sh
npm start             # http://127.0.0.1:5199
npm test
npm run build         # 编译253项资料，再输出带版本号的dist/
node scripts/audit-coverage.mjs
node scripts/publish.mjs
```

`world/index.js` 分派十种空间模型，`world/viewer.js`连接共享WebGL渲染器、相机与日光；`world/navigation.js`处理取景、安全观察点和楼层更新。`atlas/compose.js` 分配尺度与选择状态；各场景模块提供实际图解规则；`atlas-app.js` 管理交互。`data/guides/` 是手工编写的摘要，`scripts/compile-guides.mjs` 核对253项唯一性、来源和单项非文字图形变化，生成公开资料。

测试覆盖253项独立操作、所有同尺度双模式组合、整组组合、互斥／分享和具体空间关系。住宅测试包括旧十项穷举、25项双模式组合、全开／逐项移除与固定混合样本。图形差异测试不等于语义或工程正确性；目前87项测试另覆盖253项三维入口、共享限高／密度／路网、餐桌共用、楼层取消后的落脚高度、连续楼梯、有效光源及分享兼容。浏览器实查十尺度三维画面、手机布局、入口行走、夜间局部光、比较及模式切换。原生深度纹理与备用RG打包阴影路径均有本地回归场景（tests/graphics.html，不进入发布产物）。

发布脚本仅将 `dist/` 推送至本仓库 `gh-pages`，保留非强制推送。模块、样式和数据URL使用内容版本号，适配GitHub Pages子路径。

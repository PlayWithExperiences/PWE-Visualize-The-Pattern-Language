# 模式语言实验室 · Pattern Language Lab

依据 Christopher Alexander 与合作者的《A Pattern Language》，浏览全部 **253 项原书概括、出处和独立图解**，在十个尺度中组合探索。另有 **25 项住宅三维场景**，保留第一人称、自由相机和太阳时间控制。

[公开工作台](https://playwithexperiences.github.io/PWE-Visualize-The-Pattern-Language/) · [住宅三维漫游](https://playwithexperiences.github.io/PWE-Visualize-The-Pattern-Language/home.html)

## 完整图解工作台

- 区域、城市、邻里、居住与机构、建筑场地、建筑平面、建筑边缘、房间、构造、生活细节，共253项。
- 每项有问题、原书原则的独立中文概括、PDF页序、候选印刷页范围和单项图形操作。全局搜索名称、编号与内容。
- 在相同场景组合空间、路径、活动与构造；切换单项和未应用对照，查看作用与规则覆盖。75–78属于替代的居住方案。
- 跨尺度选择保留在同一方案。仅显式实现的跨尺度约束传播，例如21限制96的楼层、127改变私人床区位置、190影响构造场景的局部顶面、250改变房间暖色表面；并非所有原书关系都是自动依赖。
- 本机保存、并排比较、分享恢复、SVG导出和手机布局。
- 1,771条原书有向提及，按英文标题与括号编号同时匹配，不能视为完整网络或强制组合关系。

图解表达项目的一种解释。多个选项可能争用位置或覆盖彼此；工具会标注无额外图形变化，但不自动解决所有冲突。这不是把253项同时生成成一栋完整建筑的工程系统，也不表示253项都有写实3D模型。

## 住宅三维场景

`home.html` 保留25项参数化模型、轴测／平面／剖开外墙、人高1.65米行走、墙体和家具碰撞、自由飞行与升降、太阳时刻／流速／方位／高度。旧首页 `#v1=` 链接自动转入该场景，旧本机保存格式保留。

昼夜采用06:00日出、18:00日落的示意周期，不对应真实地理位置与季节；夜间不模拟室内灯。模型未进行结构、声学、日照、交通、无障碍或规范验算。

厨房139已放回共享侧；原有直角深窗框223和较粗窗格239仍是三维简化，完整图解分别展示向内展开的洞口与较细分格。

## 开发和验证

需要 Node.js 与 Python 3，无需安装依赖，无运行时第三方库或在线模型调用。

```sh
npm start             # http://127.0.0.1:5199
npm test
npm run build         # 编译253项资料，再输出带版本号的dist/
node scripts/audit-coverage.mjs
node scripts/publish.mjs
```

`atlas/compose.js` 分配尺度与选择状态；各场景模块提供实际图解规则；`atlas-app.js` 管理交互。`data/guides/` 是手工编写的摘要，`scripts/compile-guides.mjs` 核对253项唯一性、来源和单项非文字图形变化，生成公开资料。

测试覆盖253项独立操作、所有同尺度双模式组合、整组组合、互斥／分享和具体空间关系。住宅测试包括旧十项穷举、25项双模式组合、全开／逐项移除与固定混合样本。图形差异测试不等于语义或工程正确性，浏览器另做十尺度图解及关键流程验收。

发布脚本仅将 `dist/` 推送至本仓库 `gh-pages`，保留非强制推送。模块、样式和数据URL使用内容版本号，适配GitHub Pages子路径。
